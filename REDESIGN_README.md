# Harish Sarma — Advanced Portfolio

A custom Jekyll portfolio built around a 70% personal / interactive and 30% professional balance.

## Highlights
- Custom visual system; no Beautiful Jekyll theme dependency in the rendered UI
- Dark/light theme with saved preference
- Command palette: `Ctrl/Cmd + K`
- Scroll progress indicator
- Reveal animations and subtle 3D tilt interactions
- Magnetic buttons and cursor glow on pointer devices
- Project filters on the project archive
- AI Code Reviewer case-study modal
- Live India time on the homepage
- Responsive mobile navigation
- Dedicated About, Projects, Notes, Gallery and Post layouts
- Existing blog posts and image assets retained
- HSV Automation Hub linked as a separate project; the nested `hsv` repository is intentionally not included

## Local preview
Install Ruby + Jekyll, then run:

```bash
bundle install
bundle exec jekyll serve --livereload
```

Open `http://localhost:4000/`.

## GitHub Pages
Push the contents of this repository to the `harishsarmav/harishsarma_v` repository. GitHub Pages will build the Jekyll site using the repository's configuration.
